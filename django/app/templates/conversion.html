📡 1. Données GNSS (Traces GPS)

Les données brutes de géolocalisation issues de boîtiers GPS ou smartphones.

Schéma de données
Champ Type Obligatoire Description
user_id String / Int OUI Identifiant unique de l'utilisateur ou du véhicule.
timestamp Datetime ISO OUI Horodatage du point (YYYY-MM-DD HH:MM:SS).
latitude Float OUI Coordonnée latitude (WGS84).
longitude Float OUI Coordonnée longitude (WGS84).
speed Float OPT Vitesse instantanée en km/h.
trajectory_id String OPT ID de la trajectoire (si groupement connu).
FLAT FILE (CSV)
user_id,timestamp,latitude,longitude,speed,trajectory_id 101,2025-01-21 08:00:00,43.5231,5.4432,25.4,traj_A1 101,2025-01-21 08:00:15,43.5245,5.4450,28.1,traj_A1 102,2025-01-21 08:05:00,43.5300,5.4400,45.0,traj_B2
OBJECT (JSON)
[ { "user_id": 101, "timestamp": "2025-01-21 08:00:00", "latitude": 43.5231, "longitude": 5.4432, "speed": 25.4, "trajectory_id": "traj_A1" }, { "user_id": 101, "timestamp": "2025-01-21 08:00:15", "latitude": 43.5245, "longitude": 5.4450, "speed": 28.1, "trajectory_id": "traj_A1" } ]

📱 2. Données Telecom (Mobile Network Data)

Logs de connexion (CDR/Events) entre terminaux mobiles et antennes.

Schéma de données
Champ Type Obligatoire Description
user_id String OUI IMSI hashé ou ID abonné.
timestamp Datetime OUI Heure de l'événement.
antenna_id String OUI ID de la cellule (Cell ID).
event_type String OPT Type: CALL, SMS, DATA, HANDOVER.
CSV Example
user_id,timestamp,antenna_id,event_type User_A,2025-01-21 09:00:00,CELL_001,CALL_START User_A,2025-01-21 09:05:00,CELL_002,HANDOVER User_B,2025-01-21 09:12:30,CELL_055,SMS_SENT
JSON Example
[ { "user_id": "User_A", "timestamp": "2025-01-21 09:00:00", "antenna_id": "CELL_001", "event_type": "CALL_START", "duration_sec": 300 }, { "user_id": "User_B", "timestamp": "2025-01-21 09:12:30", "antenna_id": "CELL_055", "event_type": "SMS_SENT" } ]

🔄 3. Matrice Origine-Destination (OD)

Flux agrégés de déplacements entre zones géographiques (Zonier).

Schéma de données
Champ Type Obligatoire Description
origin_zone String OUI Code zone de départ (IRIS, Commune...).
dest_zone String OUI Code zone d'arrivée.
count Integer OUI Nombre de déplacements observés.
time_slot String/Range OPT Plage horaire (ex: "08:00-09:00").
CSV Example
origin_zone,dest_zone,count,time_slot 13001,13008,1540,H08 13008,13090,320,H08 13001,13001,500,H08
JSON Example
[ { "origin_zone": "13001", "dest_zone": "13008", "count": 1540, "settings": { "day_type": "WEEKDAY", "weather": "SUNNY" } }, { "origin_zone": "13008", "dest_zone": "13090", "count": 320 } ]
