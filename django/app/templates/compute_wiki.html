📚 Guide : Créer un Module

Documentation pour ajouter un nouveau script d'analyse à la plateforme

⚠️ Important

Pour créer un nouveau module, veuillez vous rapprocher de votre administrateur système qui pourra vous accompagner dans le déploiement.

🏗️ Architecture

Les modules d'analyse de MobiFlux utilisent l'architecture suivante :

  • Apache Spark - Traitement distribué des données
  • Celery - Gestion des tâches asynchrones
  • Redis - Broker de messages et cache
  • PostgreSQL - Stockage des données

📁 Structure des Fichiers

Un nouveau module nécessite les fichiers suivants :

1. Script Spark

Créer un fichier dans spark/app/

# spark/app/mon_module.py
from pyspark.sql import SparkSession

def run_analysis(config):
    spark = SparkSession.builder \
        .appName("MonModule") \
        .getOrCreate()
    
    # Votre logique d'analyse ici
    
    spark.stop()

2. Tâche Celery

Ajouter la tâche dans django/app/tasks.py

# tasks.py
from celery_app import app

@app.task
def run_mon_module(params):
    # Soumettre le job Spark
    pass

3. Vue Django

Créer la vue dans django/app/views/

# views/mon_module.py
from django.shortcuts import render
from django.http import JsonResponse

def mon_module_view(request):
    return render(request, 'mon_module.html')

🔧 Configuration

Pour intégrer votre module :

  • Ajouter la route dans app.py
  • Créer le template HTML correspondant
  • Ajouter la carte dans compute.html
  • Configurer les paramètres Spark si nécessaire

📞 Contact

Pour toute question ou assistance dans la création de votre module, contactez votre administrateur système qui pourra :

  • Configurer les ressources Spark nécessaires
  • Déployer le module en production
  • Gérer les permissions d'accès
  • Monitorer les performances
